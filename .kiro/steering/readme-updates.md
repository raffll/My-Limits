# README Updates

When asked to update the README, do NOT rewrite existing text with different wording. Instead:

- Analyze what is missing from the README compared to the current code.
- Analyze what has changed in the code that makes existing README content incorrect.
- Only add missing information or correct factual inaccuracies (wrong paths, wrong defaults, missing features).
- Preserve the original phrasing of everything that is still accurate.
