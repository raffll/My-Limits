# README Style

When writing or editing the README, follow this style:

- Start with a single H1 title followed by a one-line description. No badges, no banners.
- Use H2 sections for major topics. No H3 or deeper nesting.
- Keep sections short and scannable. Prefer bullet lists over paragraphs.
- Config entries use inline code for the key name, an em dash, then a brief description with default value in parentheses.
- Group config entries under bold sub-labels (e.g. **Toggles:**, **Limits:**, **Exclusions:**).
- Gameplay behavior sections describe mechanics in plain bullet points. No step-by-step tutorials.
- Lua interface section lists function signatures as inline code with a brief description after an em dash.
- Changelog is a fenced code block with version heading and bullet points.
- Installation section is allowed (brief, no badges, no screenshots).
- No requirements section beyond what's in Installation. No badges, no screenshots.
- No "Table of Contents" section.
- End with short Compatibility and Permissions sections.
- Tone: direct, concise, informative. No marketing language.
